## 关键不变量

- 只有内容真正进入 `Filtered` 状态时才产生事件。
- 同一 Content Identity 的全局统计不因刷新、DOM 重建或路由切换重复增长。
- Badge 只表示当前 Tab 当前页面生命周期，刷新归零，Tab 之间独立。
- Today 使用用户本地自然日；All Time 不因跨日或历史详情过期而减少。
- Reveal 仅是临时查看，不等于 Incorrect；只有明确操作才标记过滤错误。
- 详细历史固定保留 30 天；聚合统计长期保留。
- Activity 数据默认本地保存；同步采用稳定事件 ID 合并，重复同步不重复计数。
- 不保存完整 HTML、DOM 快照、Cookie、Session、追踪参数或不必要媒体内容。
